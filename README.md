# AmazonML2026 — Business Entity Resolution Challenge

Solution for the Amazon ML Challenge 2026 (Business Entity Resolution). Given business records
from three noisy, independent sources, find every Source-2/3 record that matches each Source-1
entity, scored on macro F0.5.

- **Full methodology write-up:** [`METHODOLOGY.md`](METHODOLOGY.md)
- **Runnable pipeline:** [`code/business_entity_resolution/`](code/business_entity_resolution/) (see its `README.md` for setup + exact reproduction commands)
- **Filled submission template:** [`AmazonML/student_resource/Documentation_template.md`](AmazonML/student_resource/Documentation_template.md)
- **Original problem statement:** [`PS.md`](PS.md)

## Result

| Version | Held-out val macro F0.5 | Public LB |
|---|---|---|
| Baseline: 16-feature LightGBM + exclusive decoder | 0.9359 | 0.922 |
| + stage-2 LightGBM stacker (OOF stage-1 preds, full competitor context) | 0.957 | 0.936 |
| + stage-2 GPU XGBoost (test-like "S1-dropped" training regime) | 0.9621 | 0.938 |
| **Final: average of two GPU XGBoost stage-2 models + expected-F0.5 decoder** | **0.9631** (US 0.9703, India 0.9523) | submitted |

Validation = 10% of train Source-1 entities, never used for training. The oracle ceiling over our
candidate set is 0.9909 on val (2.65% of true pairs are never generated as candidates). Final pipeline and
numbers are written up in [`AmazonML/student_resource/Documentation_template.md`](AmazonML/student_resource/Documentation_template.md).

**Backups:** the submitted package (`Verbatim_submission.zip`: final `matching_results.tsv`,
`candidate_pairs.tsv`, code, docs) and the final XGBoost models are attached to the GitHub Release
[`v1.0-final`](https://github.com/VeerbhadraMahant/AmazonML2026/releases/tag/v1.0-final). Training logs,
stage-2 configs and the LightGBM models are in [`results/`](results/).

## Repository layout

```
.
├── METHODOLOGY.md                          # full narrative write-up
├── PS.md, Amazon_PS.pdf, AmazonMLGuidelines.pdf   # challenge materials
├── AmazonML/student_resource/              # host-provided data + validator + doc template
```

`AmazonML/student_resource/dataset/` (the raw train/test TSVs) and `work/` are gitignored — they're
either host-provided (re-downloadable from the challenge portal) or fully regenerable by running
the pipeline described in `code/business_entity_resolution/README.md`.
